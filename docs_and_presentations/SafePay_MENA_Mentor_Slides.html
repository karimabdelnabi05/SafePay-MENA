03 • 5G CAMARA Network APIs
Slide 04 / 09

4 Core CAMARA APIs via Nokia Network-as-Code

1. SIM Swap API
2-Legged Server
POST /sim-swap/v0/check  |  POST /sim-swap/v0/retrieve-date

Queries carrier HSS/UDM database for SIM replacement timestamps within 24-48h. Detects recycled numbers by comparing IMSI activation date against bank account registration date. Latency: <150ms.

2. Number Verification API
3-Legged Cellular
POST /number-verification/v0/verify  |  GET /device-phone-number

Silently verifies device radio session over 4G/5G cellular data bearer in 300ms. Proves the user possesses the physical registered SIM without sending SMS or typing codes.

3. Device Status API (Roaming)
2-Legged Server
POST /device-status/v0/roaming  |  POST /device-status/v0/reachability

Queries international roaming country code (MCC/MNC) and handset reachability. Flags impossible travel velocity and suspicious high-risk country roaming. Latency: <120ms.

4. Device Swap API (IMEI)
2-Legged Server
POST /device-swap/v0/check

Detects if subscriber's SIM was inserted into a new hardware handset (IMEI change). Shuts down 72-hour sleeper SIM attacks by tracking physical device hardware upgrades. Latency: <140ms.

The 95% Zero-Call Strategy: Minimizing Telecom Overhead

1. Hardware Device Token

One-time cryptographic binding to Apple/Android Secure Enclave. When a user opens the app on their trusted daily phone, local device attestation approves routine transfers in 0ms.
➔ Zero Telco API calls ($0.00 cost) for 90% of daily life.

2. 3-Minute Redis Cache

Verified SIM status is cached in Redis with a 3-minute TTL. Sequential checkouts (Amazon then Talabat) hit Redis in 1ms.
➔ High-Value Bypass: Any transfer > 5,000 EGP strictly bypasses cache and queries telco live.

3. Recipient Trust Graph

Transfers to phonebook contacts (persisted > 30 days) and recurring historical payees (rent, utility bills) resolve silently with zero user friction.
➔ Anti-mule engine overrides whitelist if recipient account shows abnormal inflow.
